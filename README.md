
# Python Toolkit Project

A simple command-line toolkit with a number guessing game, to-do list, and basic calculator.

## How to Run
1. Save the `toolkit.py` file.
2. Run it using Python: `python toolkit.py`
3. Choose an option from the menu to use a tool.

## Reflection
This project helped me practice building a multi-tool CLI app in Python. The hardest part was structuring the menu loop and handling invalid inputs. I spent some time fixing an `EOFError` issue with input handling, but it got resolved. The to-do list feature was fun to implement with lists and loops. If I had one more week, I'd add a password-protected notes tool and improve error handling with more specific messages. The project was a good mix of logic and user interaction. Overall, it was a solid learning experience.
